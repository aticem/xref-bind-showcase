# XREF Bind

> 🔒 **Showcase** — the source code is private. Walkthrough available on request via [LinkedIn](https://www.linkedin.com/in/acsamiloglu/).

Takes a zipped AutoCAD drawing set and produces one clean DWG: every external reference (including nested ones) is permanently bound into the main drawing and exploded.

## Features
- Handles nested xrefs automatically
- Output looks identical, but every object can be edited on its own
- Falls back to DXF output when DWG writing isn't available
- One-command setup

## Tech stack
Python (ezdxf) · ODA File Converter · Node.js
